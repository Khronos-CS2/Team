# Khronos E-Sports

## Nova área de alunos

Foi adicionada a página `alunos.html` e o botão **ALUNOS** ao menu do site.

O produto apresentado na página é o **Treinamento de CS2 — R$ 120,00**.

### Importante sobre pagamentos

Esta versão é a camada visual/frontend. O QR Code Pix, cadastro real, login, banco de dados, confirmação automática do pagamento e liberação dos vídeos precisam de um backend.

A estrutura visual já possui:
- página de alunos;
- apresentação do treinamento;
- preço de R$ 120,00;
- telas de login e cadastro;
- modal de pagamento Pix;
- lista de aulas bloqueadas;
- espaço para incorporar vídeos do YouTube não listados;
- botões e estados preparados para futura integração com Mercado Pago.

Não coloque credenciais secretas do Mercado Pago em HTML ou JavaScript público.
